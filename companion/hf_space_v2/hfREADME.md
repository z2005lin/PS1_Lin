# Stay in the Loop

This folder contains Version 2 of the interactive Hugging Face artifact for PS1.

The game demonstrates the dynamic human–automation allocation problem studied in the proposal. Across repeated rounds, automation provides a current performance advantage, while manual control can preserve or restore human capability. Automation may become unavailable in future rounds, forcing human control.

## Files

- `index.html` — interactive browser-based game
- `README.md` — artifact documentation

## Research connection

The game illustrates the same core setting as the computational benchmark:

- automation has a current performance advantage;
- human capability changes with practice or non-practice;
- automation may become unavailable in each round;
- future emergencies can make preserved human capability valuable.

The game displays one realized stochastic trajectory. It should not be interpreted as the normative benchmark itself or as human-subject evidence.
